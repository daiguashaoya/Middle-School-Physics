噪声的危害和控制

马路上的汽车喇叭声、工地上的机器轰鸣声、深夜里邻居的音响声……噪声已经成为当代社会的四大污染之一。什么是噪声？怎样衡量噪声的强弱？又该怎样减弱噪声？

1 课时5 个互动演示1 个配套实验

🎯 学习目标

  • 能从物理学和环境保护的角度认识噪声
  • 知道噪声的来源和危害，知道用分贝表示声音的强弱等级
  • 知道减弱噪声的三条途径

⭐ 重点

  • 从物理学和环境保护两个角度认识噪声

🧩 难点

  • 判断减弱噪声的措施属于哪条途径
知识点 1

噪声的来源

🔬 从物理学角度看

噪声是发声体做 无规则振动 时发出的声音，它的波形杂乱无章；乐音的波形则有规律。

🌏 从环境保护角度看

凡是 妨碍人们正常休息、学习和工作 的声音，以及对人们要听的声音产生干扰的声音，都属于噪声。

互动：乐音与噪声的波形

动画

用示波器观察几种声音的波形。比较音叉声和铁钉刮玻璃声的波形，有什么不同？

注意：从环保角度看，乐音也可能成为噪声。比如在音乐厅里演奏的交响曲是乐音，但如果用高音喇叭在居民区不停地播放，或者深夜里有人弹琴影响别人休息，它就成了噪声。

噪声的主要来源

🚗
交通运输噪声喇叭声、汽笛声、刹车声、发动机声
🏭
工业噪声纺织厂、印刷厂、机械车间的噪声
🚧
建筑施工噪声筑路、盖楼、打桩的声音
🏬
社会生活噪声娱乐场所、商店、集贸市场的喧哗声
知识点 2

噪声的强弱等级和危害

人们以 分贝（符号 dB）为单位来表示声音强弱的等级。

0 dB 是人们刚刚能听到的最微弱的声音；30~40 dB 是较为理想的安静环境；超过 50 dB 会影响睡眠，超过 70 dB 会干扰谈话、影响工作效率，长期生活在 90 dB 以上的环境中会严重影响听力。

互动：声音的强弱等级

图表

点击图上的图标，或拖动滑块，看看不同的声音大约有多少分贝、对人有什么影响。

0 dB人刚能听到的最微弱的声音
30~40较理想的安静环境
≤ 50保证休息和睡眠
≤ 70保证工作和学习
≤ 90保护听力
150鼓膜破裂出血，双耳完全失去听力
易错：分贝（dB）表示的是声音的强弱等级（响度），不是音调；声级计（噪声监测仪）只能监测噪声的大小，并不能减弱噪声。
噪声的危害：影响休息和睡眠、干扰学习和工作、损伤听力，还会引起头痛、心血管和神经系统疾病。长时间戴耳机大音量听音乐，也会损伤听力。
知识点 3

控制噪声

减弱噪声的三条途径

① 防止噪声产生——在 声源处 减弱；② 阻断噪声传播——在 传播过程中 减弱；③ 防止噪声进入耳朵——在 人耳处 减弱。

练一练：这些措施在哪里减弱噪声？

练一练
判断方法：抓住关键词——措施作用在“发出声音的物体”上，是在声源处；作用在“声音经过的路上”（墙、树、门窗、隔音材料），是在传播过程中；作用在“人的耳朵”上，是在人耳处。

课堂活动：比较材料的隔声性能

课堂活动模拟实验

把响铃的闹钟放进鞋盒，分别用不同材料包住它。人慢慢远离盒子，直到刚好听不到铃声，记录这时的距离——距离越短，材料的隔声性能越好。

小结

本节知识梳理

噪声

  • 物理学角度：发声体做无规则振动发出的声音
  • 环保角度：妨碍休息、学习、工作的声音
  • 来源：交通、工业、施工、社会生活

强弱等级

  • 单位：分贝（dB）
  • 理想环境 30~40 dB
  • 休息 ≤ 50 dB，学习工作 ≤ 70 dB，保护听力 ≤ 90 dB

控制噪声

  • 在声源处减弱（消声器、禁鸣）
  • 在传播过程中减弱（隔音墙、植树、关窗）
  • 在人耳处减弱（耳罩、耳塞）
