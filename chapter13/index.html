第十三章　内能

花香四溢、墨水在清水中散开、搓手取暖、沿海地区冬暖夏凉……这些现象都与看不见的分子有关。本章从分子的运动和相互作用出发，认识物体的内能、改变内能的两种方式，以及描述物质吸热本领的物理量——比热容。这是九年级的第一章，也是热学的开始。

核心

核心知识与方法

分子动理论内容证据
物质的构成常见的物质由大量的分子、原子构成，分子间有间隙50 mL 水和 50 mL 酒精混合后总体积小于 100 mL
分子热运动分子在不停地做无规则运动，温度越高越剧烈扩散现象；热水中的墨水扩散得快
分子间的作用力分子之间同时存在引力和斥力铅柱“粘”在一起；固体、液体很难被压缩
改变内能实质内能增加内能减少
热传递内能的转移吸收热量（如用热水袋暖手）放出热量（如工件放入冷水中）
做功能量的转化外界对物体做功（如压缩空气、搓手）物体对外界做功（如瓶塞跳起）
热量的计算公式说明
比热容c = Q/(mΔt)单位 J/(kg·℃)；c水 = 4.2×10³ J/(kg·℃)
吸热 / 放热Q吸 = cm(t − t₀)，Q放 = cm(t₀ − t)m 用 kg；物态不变化时才适用
热平衡Q吸 = Q放不计热量损失时
要记住：一切物体都具有内能；内能 = 所有分子的动能 + 分子势能；做功和热传递改变内能是等效的；热量是过程量，只能说“吸收”“放出”；比热容只与物质的种类和状态有关；水的比热容最大。
易错：把尘土飞扬当作分子运动；认为 0 ℃ 的物体没有内能；认为温度高的物体内能一定大；说物体“含有热量”；认为物体吸热温度一定升高；把洒水降温当作利用比热容；混淆“升高了”和“升高到”；忘记把 g 换成 kg。

🔍 转换法

通过扩散现象认识看不见的分子运动；用加热时间的长短表示物质吸收热量的多少。

🎛️ 控制变量法

比较不同物质的吸热能力时，控制质量、初温、加热器相同，只改变物质的种类。

🔗 类比法

用弹簧比喻分子间的作用力；用黄豆和芝麻混合比喻分子间有间隙；用机械能类比内能。

实验

配套虚拟实验

💨 扩散现象

3D 二氧化氮和空气的扩散（瓶子对调、提高温度）；冷水和热水中滴墨水。

🔩 分子间的作用力

铅柱、玻璃板拉出水面、压缩空气和水、水和酒精混合；弹簧模型。

🔥 做功改变物体的内能

3D 压缩引火仪（迅速 / 缓慢压下）、瓶塞跳起出现白雾；搓手、钻木取火。

♨️ 热传递与热量

热传导、对流、热辐射；高温和低温的物体接触，直到温度相同。

🌡️ 比较不同物质的吸热能力

3D 电加热器、水和食用油（煤油），两种方案，自动记录与图像；用煤气灶烧水。

⚗️ 测量金属块的比热容

沸水中的金属块放入量热器，用 Q吸 = Q放 算比热容、判断金属；热量计算器。
