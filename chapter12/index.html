第十二章　简单机械

一根撬棒能撬起千斤重的石头，旗杆顶上的小轮子能让国旗升到高处，几个滑轮就能把沉重的建材吊上楼……杠杆、滑轮、轮轴、斜面都是简单机械。本章研究杠杆的平衡条件和滑轮的特点，并认识机械效率。这是八年级下册的最后一章。

核心

核心知识与方法

杠杆力臂关系特点实例
省力杠杆l₁ > l₂省力，费距离撬棒、羊角锤、瓶起子、独轮车
费力杠杆l₁ < l₂费力，省距离镊子、筷子、钓鱼竿、人的前臂
等臂杠杆l₁ = l₂不省力，也不省距离托盘天平
定滑轮动滑轮滑轮组
实质等臂杠杆l₁ = 2l₂ 的省力杠杆—
拉力（不计绳重和摩擦）F = GF = (G + G动)/2F = (G + G动)/n
绳端移动距离s = hs = 2hs = nh
改变力的方向能不能看绕法
机械效率有用功总功公式
滑轮组（竖直提升）GhFsη = G/(nF)；不计绳重和摩擦时 η = G/(G + G动)
滑轮组（水平拉动）fs物Fs绳η = f/(nF)
斜面GhFLη = Gh/(FL)
要记住：F₁l₁ = F₂l₂；力臂是支点到力的作用线的距离；“奇动偶定”；省力的机械必然费距离，使用任何机械都不省功；机械效率总小于 1；同一滑轮组提升的物体越重，机械效率越高。
易错：把支点到作用点的距离当作力臂；实验中挂钩码后又调平衡螺母；斜拉弹簧测力计时示数变大；动滑轮只有竖直拉才省一半力；水平拉动时滑轮组克服的是摩擦力；静止时读数使测得的机械效率偏大；机械效率高≠功率大≠省力。

✏️ 模型法

把撬棒、羊角锤、滑轮等抽象成一根绕支点转动的杠杆，画出杠杆示意图。

📊 归纳法

探究杠杆的平衡条件时，改变钩码的个数和位置多次实验，从数据中寻找普遍规律。

🎛️ 控制变量法

探究滑轮组、斜面的机械效率跟哪些因素有关时，每次只改变一个因素。

实验

配套虚拟实验

⚖️ 探究杠杆的平衡条件

3D 杠杆：调平衡螺母、挂钩码、弹簧测力计竖直和斜着拉，自动记录与分析；杆秤。

🔨 省力杠杆和费力杠杆

拖动支点和力的作用点，比较力和距离；找出最小的动力。

🏗️ 研究定滑轮和动滑轮的特点

3D 铁架台、滑轮、钩码和弹簧测力计；滑轮的实质。

⚙️ 组装滑轮组

5 种绕法，数绳子段数，竖直提升和水平拉动；轮轴。

📈 测量滑轮组的机械效率

3D 甲、乙两个滑轮组，读数、计算 η、分析论证；η 与物重的关系图像。

📐 测量斜面的机械效率

改变倾斜程度、接触面和物重；斜面省力但费距离。
