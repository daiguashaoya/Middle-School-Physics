机械效率

使用机械可以省力，可是能省功吗？用动滑轮提升重物时，人不仅要提起重物，还要提起动滑轮、克服摩擦——做的功总比直接提重物多。这一节认识有用功、额外功和总功，学习机械效率，并动手测量滑轮组和斜面的机械效率。

2 课时6 个互动演示2 个配套实验

🎯 学习目标

  • 知道有用功、额外功和总功的含义及三者的关系
  • 理解机械效率的概念，会计算机械效率，知道机械效率总小于 1
  • 会测量滑轮组和斜面的机械效率，知道提高机械效率的方法

⭐ 重点

  • 机械效率的概念和计算
  • 测量滑轮组的机械效率

🧩 难点

  • 在实例中判断有用功、额外功和总功
  • 影响机械效率的因素
知识点 1

有用功、额外功和总功

要把 100 N 的沙子运上三楼，可以提着桶走上去，也可以用动滑轮把桶或口袋拉上去。三种方法对沙子做的功一样多，可是人做的功却差别很大——多做的功做到哪里去了？

动画：三种方法把沙子运上三楼

动画重点

三种方法都试一试，比较有用功、额外功和总功。

✅ 有用功 W有

为了达到目的必须要做的功，如对沙子做的功。

➕ 额外功 W额

对人们没有用、但又不得不做的功，如克服机械自身部件的重力（桶、动滑轮）和摩擦做的功。

Σ 总功 W总

有用功与额外功之和，也就是动力（拉力）做的功：W总 = W有 + W额。

机械有用功 W有总功 W总额外功 W额
滑轮组竖直提升重物GhFs（s = nh）克服动滑轮重和摩擦做的功
滑轮组水平拉动物体fs物（克服摩擦力）Fs绳（s绳 = ns物）克服绳与轮之间的摩擦做的功
斜面GhFL（L 为斜面长）克服斜面摩擦力做的功 fL
想一想　用水桶从井里提水，对水做的功是有用功还是额外功？如果水桶掉进井里，把水桶捞上来时，桶里带了一些水，对水做的功又是什么功？
看解答

提水时目的是水：对水做的功是有用功，对桶做的功是额外功。捞桶时目的是桶：对桶做的功是有用功，对水做的功是额外功。有用功和额外功是相对的，要看做功的目的。

知识点 2

机械效率

机械效率

物理学中，将有用功跟总功的比值叫做机械效率，用 η 表示：

η = W有W总 × 100%

机械效率是一个比值，没有单位，通常用百分数表示。使用任何机械都不可避免地要做额外功，有用功总小于总功，所以机械效率总小于 1。机械效率越高，有用功在总功中所占的比例越大，机械的性能越好。

🏗️ 起重机

约 40%～50%

⚙️ 滑轮组

约 50%～70%

💧 抽水机

约 60%～80%

例　起重机把重 3 600 N 的货物匀速提高 4 m，如果额外功是 9 600 J，起重机做的有用功是多少？总功是多少？机械效率是多少？起重机在哪些方面消耗了额外功？
看解答

起重机提升货物的力 F = G = 3 600 N，
有用功 W有 = Gh = 3 600 N × 4 m = 1.44×10⁴ J；
总功 W总 = W有 + W额 = 14 400 J + 9 600 J = 2.4×10⁴ J；
机械效率 η = W有W总 = 1.44×10⁴ J2.4×10⁴ J = 60%。
额外功消耗在：克服吊钩、钢绳等机械部件的重力做功，克服各部件之间的摩擦做功。

计算器：η = W有/W总

工具

选择要求的量，填入已知量后计算；也可以点下面的例子。

易错：①机械效率高，只说明有用功占总功的比例大，不等于做功快（功率大），也不等于做的有用功多、更省力；②同一机械在不同的做功过程中（如提升的物重不同），机械效率可以不同，机械效率不是固定不变的。
知识点 3

测量滑轮组的机械效率

📐 实验原理

η = W有W总 = GhFs。需要测量：钩码的重 G、钩码上升的高度 h、拉力 F、绳端移动的距离 s。

🔧 实验器材

铁架台、两个滑轮组（甲、乙）、钩码、弹簧测力计、刻度尺、细绳。

实验步骤：①用弹簧测力计测出钩码的重 G；②记下钩码和绳端（弹簧测力计）的位置；③竖直向上匀速拉动弹簧测力计，使钩码升高，读出拉力 F，用刻度尺测出钩码上升的高度 h 和绳端移动的距离 s；④算出有用功、总功和机械效率；⑤改变钩码的重、换另一个滑轮组，再做几次。

3D 实验：测量滑轮组的机械效率

3D 模型重点

选择滑轮组和钩码，拉动弹簧测力计，读出 G、h、F、s，算出机械效率填进去，检查正确后记录。改变钩码的重、提升的高度和滑轮组，再试试“静止时读数”。

实验中的注意事项：①要竖直向上匀速拉动弹簧测力计，边拉边读数；若在弹簧测力计静止时读数，没有测出摩擦的影响，拉力偏小，测得的机械效率偏大。②由 η = GhFs = GhF·nh = GnF 可知，没有刻度尺也能测出滑轮组的机械效率。
结论：①同一滑轮组，提升的物体越重，机械效率越高；②提升相同的物体，动滑轮越多（越重），额外功越多，机械效率越低；③机械效率与物体被提升的高度、绳子的绕法无关。
提高滑轮组机械效率的方法：增加物重、减小动滑轮的重、减小摩擦（如给滑轮的轴加润滑油）。

图像：机械效率与物重、动滑轮重的关系

图像

拖动滑块改变物重，切换动滑轮的重和有无摩擦，观察机械效率的变化。

不计绳重和摩擦时：额外功只是克服动滑轮重做的功 W额 = G动h，η = GhGh + G动h = GG + G动。
知识点 4

测量斜面的机械效率

沿斜面把木块匀速拉到顶端，有用功是把木块提高 h 所做的功 W有 = Gh，总功是拉力做的功 W总 = Fs（s 为斜面长），额外功是克服摩擦力做的功。

实验：测量斜面的机械效率

动手常考

改变斜面的倾斜程度、接触面和木块的重，沿斜面匀速拉动木块，读出拉力，算出机械效率后记录，分析机械效率跟哪些因素有关。

结论：斜面的机械效率跟斜面的倾斜程度和粗糙程度有关：接触面相同时，斜面越陡，机械效率越高（但越费力）；倾斜程度相同时，接触面越光滑，机械效率越高。

练一练：机械效率的计算

随机出题常考

起重机、滑轮组（竖直和水平）、斜面，题目随机生成。机械效率填百分数中的数字。

小结

本节知识梳理

三种功

  • 有用功：必须要做的功
  • 额外功：不需要但又不得不做的功
  • W总 = W有 + W额

机械效率

  • η = W有/W总，没有单位，用百分数表示
  • 机械效率总小于 1
  • 不是固定不变的

滑轮组

  • η = Gh/(Fs) = G/(nF)
  • 不计绳重和摩擦：η = G/(G + G动)
  • 竖直向上匀速拉动弹簧测力计

提高机械效率

  • 滑轮组：增加物重、减轻动滑轮重、减小摩擦
  • 斜面：增大倾斜程度、减小粗糙程度
