滑轮

升旗时向下拉绳子，国旗却向上升；建筑工地上，工人用几个滑轮就能把沉重的建材吊上楼。这一节认识定滑轮、动滑轮和滑轮组，看看它们各有什么特点，再认识轮轴和斜面这两种简单机械。

知识点 1

定滑轮和动滑轮

旗杆有十几米高，手够不到顶端，怎样把国旗升上去？旗杆顶上有一个小轮子——滑轮。

滑轮

周边有槽、能绕轴转动的小轮叫做滑轮。使用时轴固定不动的滑轮叫做定滑轮（如旗杆顶端的滑轮）；轴和重物一起移动的滑轮叫做动滑轮（如起重机吊钩上的滑轮）。

3D 实验：研究定滑轮和动滑轮的特点

3D 模型重点

先直接用弹簧测力计提起钩码测出 G；再分别使用定滑轮（三个方向）和动滑轮（竖直、斜着）匀速拉动，比较拉力 F 与 G、绳端移动的距离 s 与钩码上升的高度 h。

定滑轮动滑轮
力的关系F = G（不省力）F = G + G动2（不计动滑轮重时 F = G2，省一半力）
距离的关系s = h（不省距离）s = 2h（费距离）
力的方向可以改变力的方向不能改变力的方向
应用旗杆顶端的滑轮、升降晾衣架上的滑轮起重机吊钩上的滑轮
注意：实验中拉力略大于理论值，是因为绳与滑轮之间有摩擦、绳子有重力；使用动滑轮时拉力略大于物重的一半，还因为动滑轮本身有重力。
知识点 2

定滑轮和动滑轮的实质

滑轮其实是一种变形的杠杆。找出它的支点和两个力臂，就能明白它为什么省力或不省力。

动画：滑轮是变形的杠杆

动画难点

切换定滑轮和动滑轮，看红色的“杠杆”和它的两个力臂；拖动滑块改变拉力的方向，观察力臂和拉力的变化。

定滑轮：等臂杠杆

支点在轴上，l₁ = l₂ = r（轮的半径），所以 F = G。沿任何方向拉，力臂都是半径 r，拉力不变。

动滑轮：l₁ = 2l₂ 的省力杠杆

支点在左边绳子与轮子相切的地方，l₁ = 2r，l₂ = r，所以 F = G/2。只有竖直向上拉时才省一半力，斜着拉时动力臂变短，拉力变大。

想一想　定滑轮左端的绳子下挂着重物，在右端的绳子自由端分别沿竖直向下、斜向下、水平三个方向用力，力的大小分别为 F₁、F₂、F₃（不计摩擦），哪个力最大？
看解答

三个力一样大。定滑轮是等臂杠杆，沿不同方向拉时，力臂都等于滑轮的半径，拉力都等于物重。

知识点 3

滑轮组

定滑轮可以改变力的方向，动滑轮可以省力。想既省力又改变力的方向，就把定滑轮和动滑轮组合在一起——滑轮组。

滑轮组的特点

使用滑轮组提升重物时，动滑轮和重物由几段绳子吊着（承担），提起物体所用的力就是物重的几分之一：

F = Gn（不计动滑轮重和摩擦）　F = G + G动n（不计绳重和摩擦）

绳子自由端移动的距离 s = nh，速度 v绳 = nv物。n 是与动滑轮相连（承担物重）的绳子段数。

动手：组装滑轮组

动画重点

选择一种绕法，数一数承担物重的绳子段数 n；点“拉动绳子”比较 s 与 h。切换到“水平拉动物体”，看看滑轮组怎样克服摩擦力。

数绳子段数的方法：在定滑轮和动滑轮之间画一条虚线，只数与动滑轮（包括动滑轮的框架）相连的绳子段数。绳子的起点挂在动滑轮上时 n 为奇数，挂在定滑轮上时 n 为偶数——“奇动偶定”。要最省力，就从动滑轮开始绕。
水平拉动物体时：滑轮组克服的是物体受到的摩擦力 f，而不是重力：F = fn（不计滑轮重和绳与轮之间的摩擦），s绳 = ns物。
例　用动滑轮上有 3 段绳子的滑轮组，把重 600 N 的物体匀速提升 2 m，动滑轮重 30 N，不计绳重和摩擦。求拉力的大小和绳子自由端移动的距离。
看解答

F = G + G动n = 600 N + 30 N3 = 210 N；
s = nh = 3 × 2 m = 6 m。

滑轮组的优点：有的滑轮组既能省力又能改变力的方向（绳子自由端从定滑轮引出、向下拉），有的只能省力、不能改变力的方向（绳子自由端从动滑轮引出、向上拉）。
知识点 4

轮轴和斜面

轮轴

由一个轮和一个轴组成、能绕共同的轴线转动的简单机械叫做轮轴。轮轴的实质是可以连续转动的杠杆，支点在轴线上：F₁R = F₂r。动力作用在轮上时省力、费距离。

动画：轮轴（辘轳）

动画

改变轮和轴的半径，点“转动一圈”比较手和水桶移动的距离；再试试“反过来用”。

🚗 方向盘

方向盘是轮，转向轴是轴，轻轻转动方向盘就能使车轮转向。

🚪 门把手

把手是轮，锁芯的转轴是轴，把手越长越省力。

🔧 螺丝刀、水龙头

粗的手柄（轮）带动细的刀杆或阀杆（轴）转动。

斜面

斜面也是一种简单机械。使用斜面可以省力：斜面越平缓（越长），越省力，但移动的距离也越长。盘山公路、螺丝钉的螺纹、搬运货物用的跳板都是斜面。

动画：用斜面把箱子推上平台

动画

选择斜面的长度，把重 600 N 的箱子推上 1 m 高的平台，比较推力、移动的距离和做的功。

使用任何机械都不省功：省力的机械必然费距离，省距离的机械必然费力。不计摩擦和机械自重时，用机械做的功等于不用机械直接做的功。

小结

本节知识梳理

定滑轮

  • 轴固定不动
  • 等臂杠杆：F = G，s = h
  • 可以改变力的方向

动滑轮

  • 轴随物体一起移动
  • l₁ = 2l₂ 的省力杠杆
  • F = (G + G动)/2，s = 2h，不能改变方向

滑轮组

  • F = (G + G动)/n，s = nh，v绳 = nv物
  • n：与动滑轮相连的绳子段数
  • 水平拉动：F = f/n

轮轴和斜面

  • 轮轴：F₁R = F₂r
  • 斜面越平缓越省力
  • 使用任何机械都不省功
