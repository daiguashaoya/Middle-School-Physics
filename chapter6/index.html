核心

核心知识与方法

物理量符号定义 / 公式单位与换算测量工具
质量m物体所含物质的多少kg；1 t = 10³ kg，1 kg = 10³ g，1 g = 10³ mg托盘天平
体积V物体所占空间的大小m³；1 m³ = 10³ dm³ = 10⁶ cm³，1 L = 1 dm³，1 mL = 1 cm³量筒、刻度尺
密度ρρ = mV，变形 m = ρV，V = mρkg/m³；1 g/cm³ = 10³ kg/m³天平 + 量筒（间接测量）
要记住：ρ水 = 1.0×10³ kg/m³（1 g/cm³），ρ冰 = 0.9×10³ kg/m³，ρ酒精 = 0.8×10³ kg/m³，ρ铁 = 7.9×10³ kg/m³，ρ铝 = 2.7×10³ kg/m³；水在 4 ℃ 时密度最大。
易错：质量是物体的属性（与形状、状态、温度、位置无关）；密度是物质的特性（与质量、体积无关，但随状态、温度变化）。天平“左偏右调”；量筒“俯大仰小”；测固体密度先测质量后测体积。

➗ 比值定义法

用质量与体积的比值定义密度（速度也是这样定义的）。

📈 控制变量法与图像法

探究质量与体积的关系：同种物质只改变体积，画 m–V 图像。

💧 等量替代法与累积法

排水法、溢水法测体积；测 100 枚大头针的质量再除以 100。
