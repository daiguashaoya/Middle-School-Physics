核心

核心知识与方法

吸热的三种

熔化：固 → 液
汽化：液 → 气（蒸发、沸腾）
升华：固 → 气

放热的三种

凝固：液 → 固
液化：气 → 液（降温、压缩体积）
凝华：气 → 固

“温度不变”的两个过程

晶体熔化（凝固）：吸热（放热），温度不变
液体沸腾：吸热，温度不变

要记住的数据内容
0 ℃ / 100 ℃1 个标准大气压下，冰水混合物的温度 / 沸水的温度
35 ~ 42 ℃，0.1 ℃体温计的量程和分度值；人体正常体温约 37 ℃
48 ℃ / 0 ℃海波的熔点 / 冰的熔点（凝固点与熔点相同）
−39 ℃ / −117 ℃水银 / 酒精的凝固点：寒冷地区测气温用酒精温度计
78 ℃ / 357 ℃酒精 / 水银的沸点：测沸水温度用水银温度计

📈 图像法

用温度—时间图像处理熔化、凝固、沸腾的数据，一眼看出“温度不变”的水平线段。

🎛️ 控制变量法

探究影响蒸发快慢的因素时，每次只改变温度、表面积、空气流速中的一个。

🔍 三步法

判断物态变化：看初态 → 看末态 → 定名称，再判断吸热还是放热。
