# 看得见的物理 · 初中物理互动动画课堂

面向初中物理（人教版）的互动教学网站。用**动画**、**3D 模型**和**虚拟实验台**，帮助学生理解每一章的知识点。

目前已完成：**八年级上册 第1章 机械运动、第2章 声现象、第3章 物态变化、第4章 光现象、第5章 透镜及其应用、第6章 质量与密度**（八年级上册全部完成），**八年级下册 第7章 力**。

## 使用方法

- **在线访问**：在 GitHub 仓库的 *Settings → Pages* 中，选择 `main` 分支、根目录 `/`，保存后即可通过 `https://<用户名>.github.io/Middle-School-Physics/` 访问。
- **离线使用**：下载整个文件夹，直接双击 `index.html` 即可在浏览器中打开（不需要安装任何软件，也不依赖外网）。
- **课堂投影**：每个互动演示右上角都有“全屏”按钮。
- 推荐使用最新版 Chrome / Edge 浏览器。

## 添加新内容

完整的规范和操作清单见 [`任务书.md`](任务书.md)。

页面里写一个占位元素，脚本会自动挂载对应的互动组件：

```html
<div data-widget="incline-3d"></div>
<div data-quiz="s4"></div>  <!-- 题目写在 window.QUIZ.s4 -->
```

新组件用 `PS.register('名字', function (el, opts) { ... })` 注册，放在 `assets/js/widgets/` 下，并在页面中引入即可。
实验台的实验列表在 `lab/index.html` 的 `EXPERIMENTS` 数组中配置。
