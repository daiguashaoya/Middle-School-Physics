# 看得见的物理 · 初中物理互动动画课堂

面向初中物理（人教版）的互动教学网站。用**动画**、**3D 模型**和**虚拟实验台**，帮助学生理解每一章的知识点。

目前已完成：**八年级上册 第1章 机械运动**。

## 内容一览

| 页面 | 互动内容 |
| --- | --- |
| 首页 `index.html` | 章节导航、频闪照片动画 |
| 第1章概览 `chapter1/index.html` | 知识导图、核心公式、配套实验入口、章末综合练习 |
| 第1节 长度和时间的测量 | 尺度之旅（nm → km）、单位换算阶梯、认识刻度尺、刻度尺读数练习（放大镜 / 零刻度磨损）、视线斜视误差、四种特殊测量方法动画（累积法 / 滚轮法 / 卡尺法）、机械停表操作与读数、估测 1 分钟、多次测量求平均值（误差与错误） |
| 第2节 运动的描述 | 机械运动动画卡片、**3D 参照物实验室**（切换参照物，镜头跟随）、诗词中的参照物、空中加油 / 收割机与卡车 / 同步卫星 |
| 第3节 运动的快慢 | 百米赛跑（两种比较方法）、速度公式三角形计算器、m/s 与 km/h 换算、速度排行榜、频闪照片 + s–t / v–t 图像、可拖动的 s–t 图像编辑器、平均速度 ≠ 速度的平均值 |
| 第4节 测量平均速度 | **3D 斜面小车实验**（真实物理、可调坡度和金属片位置、电子计时 / 停表人工计时、自动数据分析、位移传感器 v–t 图）、超声波测速动画 |
| 物理实验台 `lab/index.html` | 刻度尺测长度、累积法测铜丝直径 / 纸厚、停表与估测、参照物观察室、测量小车平均速度、超声波测速 |

每节末尾都有即时判分、带解析的**随堂练习**。

## 使用方法

- **在线访问**：在 GitHub 仓库的 *Settings → Pages* 中，选择 `main` 分支、根目录 `/`，保存后即可通过 `https://<用户名>.github.io/Middle-School-Physics/` 访问。
- **离线使用**：下载整个文件夹，直接双击 `index.html` 即可在浏览器中打开（不需要安装任何软件，也不依赖外网）。
- **课堂投影**：每个互动演示右上角都有“全屏”按钮。
- 推荐使用最新版 Chrome / Edge 浏览器。

## 添加新内容

完整的规范和操作清单见 [`任务书.md`](任务书.md)。

页面里写一个占位元素，脚本会自动挂载对应的互动组件：

```html
<div data-widget="incline-3d"></div>
<div data-quiz="s4"></div>  <!-- 题目写在 window.QUIZ.s4 -->
```

新组件用 `PS.register('名字', function (el, opts) { ... })` 注册，放在 `assets/js/widgets/` 下，并在页面中引入即可。
实验台的实验列表在 `lab/index.html` 的 `EXPERIMENTS` 数组中配置。
