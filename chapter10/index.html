核心

核心知识与方法

求浮力的方法公式适用情况
称重法F浮 = G − F示用弹簧测力计称量
压力差法F浮 = F向上 − F向下已知上、下表面受到的压力
阿基米德原理法F浮 = G排 = ρ液gV排已知 ρ液 和 V排（任何情况）
平衡法F浮 = G漂浮、悬浮
上浮下沉悬浮漂浮沉底
受力F浮 > GF浮 < GF浮 = GF浮 = GF浮 + F支 = G
密度（实心）ρ物 < ρ液ρ物 > ρ液ρ物 = ρ液ρ物 < ρ液ρ物 > ρ液
V排= V物= V物= V物< V物= V物
要记住：浮力的方向竖直向上；F浮 = G排 = ρ液gV排，只与 ρ液 和 V排 有关；漂浮时 V排/V物 = ρ物/ρ液；排水量是轮船满载时排开水的质量；潜水艇靠改变自身重力上浮和下潜；密度计的刻度上小下大、上疏下密。
易错：下沉的物体也受浮力；下表面与容器底紧密接触的物体（桥墩）不受浮力；浸没后浮力与深度无关；V排 不一定等于 V物；求浮力先判断物体的状态；轮船从河里驶入海里浮力不变；漂浮的冰熔化后液面不变。

🎛️ 控制变量法

探究浮力的大小跟浸在液体中的体积、液体的密度、浸没的深度、物体的密度的关系。

🔍 转换法与称重法

用测力计示数的减小量表示浮力；用橡皮膜的凹陷程度显示液体的压力；用溢出的液体表示 V排。

🧠 推理与模型

用液体压强推出浮力是上、下表面的压力差；用浮沉条件推出冰熔化后液面的变化。
