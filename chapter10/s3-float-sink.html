物体的浮沉条件及应用

钢铁做的轮船为什么能浮在水面上？潜水艇怎样潜入水下又浮上来？热气球为什么能飞上天？这一节研究物体的浮沉条件，认识轮船、潜水艇、气球和密度计。

知识点 1

物体的浮沉条件

浸没在液体中的物体受到竖直向下的重力和竖直向上的浮力。物体是上浮还是下沉，取决于这两个力的大小关系。用一个能装水的小瓶来试一试。

动手：小瓶的浮沉

动手重点

改变小瓶中装水的多少（改变重力），把小瓶浸没后松手，观察它的运动和最后的状态；换一种液体（改变浮力）再试试。

状态受力关系密度关系（实心物体）V排 与 V物特点
上浮F浮 > Gρ液 > ρ物V排 = V物运动过程，最后漂浮
下沉F浮 < Gρ液 < ρ物V排 = V物运动过程，最后沉底
悬浮F浮 = Gρ液 = ρ物V排 = V物静止在液体内任意深度
漂浮F浮 = Gρ液 > ρ物V排 < V物静止在液面，一部分露出
沉底F浮 + F支 = Gρ液 < ρ物V排 = V物静止在容器底
悬浮和漂浮：相同点是都处于平衡状态，F浮 = G；不同点是悬浮时物体浸没（V排 = V物），漂浮时物体有一部分露出液面（V排 < V物）；实心物体悬浮时 ρ物 = ρ液，漂浮时 ρ物 < ρ液。
知识点 2

浮沉与密度

物体浸没时 V排 = V物，F浮 = ρ液gV物，G = ρ物gV物，比较浮力和重力，就是比较 ρ液 和 ρ物。

动画：六个体积相同的实心球

动画

换不同的液体，看看哪些球漂浮、哪些沉底，漂浮的球有多少浸在液体中。试试水银！

用密度判断浮沉

ρ物 < ρ液，上浮，最后漂浮；ρ物 = ρ液，悬浮；ρ物 > ρ液，下沉。这里的 ρ物 是物体的平均密度：铁做成空心的，平均密度可以比水小。

动手：让鸡蛋浮起来

动手

鸡蛋在清水中下沉。一勺一勺地往水中加盐并搅拌，看看鸡蛋怎样运动；再加清水试试。

常用推论：①物体漂浮时，V排V物 = ρ物ρ液——物体的密度是液体的几分之几，就有几分之几浸在液体中；②密度均匀的物体悬浮（漂浮）时，把它切成大小不等的两块，两块仍悬浮（漂浮）；③要把漂浮的物体全部按入液体中，所加的力等于浮力的增加量。

想一想：冰熔化后液面怎样变化？

动画难点

选择一种情况，先猜一猜，再点“开始熔化”。右边的放大图把液面的变化放大了。

例 1　质量相等的实心铝球和铁球放在水中，铁球受到的浮力______铝球受到的浮力；若把它们都放在水银中，静止时铁球受到的浮力______铝球受到的浮力。（均选填“大于”“小于”或“等于”）
看解答

在水中都沉底，V排 = V物，铁的密度大、体积小，浮力小于铝球；在水银中都漂浮，F浮 = G，质量相等，浮力等于铝球。

例 2　重为 15 N 的物体浸没于装满水的容器中，溢出了 5×10⁻⁴ m³ 的水。这个物体最后会怎样？（g 取 10 N/kg）
看解答

浸没时 F浮 = ρ水gV排 = 1.0×10³ kg/m³ × 10 N/kg × 5×10⁻⁴ m³ = 5 N < G = 15 N，物体沉到水底。

求浮力先看状态：漂浮、悬浮时用平衡法 F浮 = G；沉底时用阿基米德原理 F浮 = ρ液gV物。
知识点 3

浮力的应用

🚢 轮船

橡皮泥的密度比水大，捏成球会沉下去，捏成小船却能浮在水面上，还能装“货物”。

动手：橡皮泥小船与轮船

动手重点

把橡皮泥捏成小船，再放硬币，看看小船最多能装多少；切换到轮船，改变货物的多少，让它从河里驶入海里。

轮船

用密度比水大的钢铁制成空心的轮船，可以排开更多的水，增大浮力，所以能漂浮在水面上。轮船的大小通常用排水量表示——轮船满载时排开水的质量：F浮 = G排 = m排g。轮船漂浮，从河里驶入海里时，F浮 = G 不变，海水密度大，V排 变小，船身上浮一些。

🛳️ 潜水艇

3D 模型：潜水艇

3D 模型重点

向水舱充水或用压缩空气排水，观察潜水艇的重力、浮力和运动；用“微调”试着让它悬浮；再换成江水试试。

潜水艇

潜水艇浸没后 V排 不变，浮力不变。它靠改变自身的重力实现上浮和下潜：向水舱中充水，重力增大，下潜；用压缩空气排出水舱中的水，重力减小，上浮。潜水艇在水下从海里驶入江里，浮力变小，要排出一部分水才能保持悬浮。

🎈 气球和飞艇

动画：热气球

动画

点火加热，观察球内空气的温度和密度、浮力和总重力的变化；停止加热，热气球会怎样？

气球和飞艇

气球和飞艇内充有密度小于空气的气体（氢气、氦气或热空气），受到的空气浮力大于自身的重力，就能升空。热气球加热时，球内空气的密度变小，总重力减小而上升；停止加热，球内空气变冷、密度变大，热气球下降。

🧪 密度计

动手：密度计

动手

把密度计放进不同的液体，读出液体的密度；再用吸管和铜丝做一个简易密度计。

密度计

密度计是测量液体密度的仪器，下端的铅粒使它能竖直漂浮在液体中。在任何液体中都漂浮，F浮 = G 不变；液体的密度越大，V排 越小，露出液面的部分越多。所以密度计的刻度上小下大、上疏下密。

分一分：利用了浮力吗？

练一练

判断每个实例是不是利用了浮力。

生活中的浮沉：煮饺子时，饺子熟了体积变大、浮力增大，浮出水面；盐水选种时，饱满的种子密度大，下沉，干瘪的种子浮起来被清除；鱼靠鱼鳔改变排开水的体积来上浮和下沉。
小结

本节知识梳理

浮沉条件

  • F浮 > G 上浮，F浮 < G 下沉
  • F浮 = G 悬浮或漂浮
  • 沉底：F浮 + F支 = G

浮沉与密度

  • ρ物 < ρ液 上浮（漂浮）
  • ρ物 = ρ液 悬浮
  • ρ物 > ρ液 下沉

轮船与潜水艇

  • 轮船：空心，增大 V排
  • 排水量：满载时排开水的质量
  • 潜水艇：改变自身重力

气球与密度计

  • 气球：充密度小于空气的气体
  • 密度计：漂浮，F浮 = G
  • 刻度上小下大、上疏下密
